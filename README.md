# -Sentiment-Analysis-on-IMDb-Movie-Reviews-using-Custom-LSTM
Developed a custom deep learning sequence classification pipeline in Python and TensorFlow/Keras to analyze sentiment across 50,000 IMDb movie reviews, achieving 84.74% test accuracy and a 0.85 F1-score. The architecture incorporates Embedding, LSTM, and Dropout layers alongside sequence padding and EarlyStopping callbacks to prevent overfitting, supported by comprehensive performance evaluation using confusion matrices and training curves.
